# Competitive Programming

A collection of competitive programming solutions, algorithms, data structures, and problem-solving notes written primarily in **C++**.

The repository documents my progression through competitive programming, from individual online judge problems to reusable implementations of fundamental algorithms and data structures.

---

## Repository Structure

The repository is divided into two main areas:

### 🧩 Online Judge Solutions

Solutions to problems from competitive programming platforms and contests.

| Directory                      | Platform         |
| ------------------------------ | ---------------- |
| [`AtCoder/`](./AtCoder/)       | AtCoder          |
| [`CSES/`](./CSES/)             | CSES Problem Set |
| [`Codeforces/`](./Codeforces/) | Codeforces       |
| [`Kattis/`](./Kattis/)         | Kattis           |
| [`Olinfo/`](./Olinfo/)         | OII / Olinfo     |
| [`USACO/`](./USACO/)           | USACO            |
| [`Terry/`](./Terry/)           | Terry            |

Each problem is organized according to its source contest or problem set.

### 📚 Algorithm & Data Structure Implementations

The [`Implementation/`](./Implementation/) directory contains standalone implementations of algorithms and data structures that are useful in competitive programming.

Current topics include:

* Backtracking
* Data Structures
* Dynamic Programming
* Graph Algorithms
* Greedy Algorithms
* Mathematics
* Searching
* Sorting
* String Algorithms

These implementations are intended to be reusable references rather than solutions to a single online judge problem.

## Repository Philosophy

This repository is both a **problem archive** and a **personal reference library**.

Online judge solutions show how I approach concrete problems, while the implementation section collects algorithms and data structures that can be reused across different problems.
